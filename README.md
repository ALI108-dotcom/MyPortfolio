## 🌟 Overview

A professional, high-performance, and visually distinctive personal portfolio website for **Shaik Ali Ahammad**, an Artificial Intelligence and Data Science scholar. Reverse-engineered with design fidelity inspired by elite civic design standards, incorporating interactive data science showcases, continuous learning logs, verified projects, video walkthroughs, and a password-protected Dynamic Content Management System (CMS).

---

## 🚀 Key Features

- **Civic Design & High Visual Fidelity:** Editorial typography, civic grid backgrounds, signature gradient rules, and responsive design across desktop, tablet, and mobile.
- **Dynamic Content Management System (CMS):**
  - Protected by keyboard shortcut (`Ctrl + Shift + E`) and password authentication.
  - Full CRUD operations for Skills, Featured Projects, Learning Journey, Certifications, Achievements, Experience, and Education.
  - Draft vs. Published status toggles for every item.
  - Persistent server disk storage.
- **Embedded Introduction Video Showcase:**
  - Interactive video player with 3–13 minute support (YouTube, Vimeo, MP4).
  - One-click toggle between Video walkthrough and 4-step Analytical Philosophy (`Ingest` → `Explore` → `Visualize` → `Predict`).
- **File Explorer Profile Photo Selection:**
  - Ability to choose and update the profile portrait directly from the system File Explorer with automatic optimization.
- **Verified Data Science Showcases:**
  - Titanic Dataset Exploratory Data Analysis.
  - Interactive Power BI Sales Analytics & Dashboards.
  - Predictive modeling pipelines with Python, Pandas, Scikit-Learn.
- **Portable Offline Single-File HTML:**
  - Self-contained portable build available at `dist/portable-portfolio.html` requiring zero server dependencies.

## 💻 Getting Started Locally

### Prerequisites
- Node.js (v18 or higher recommended)
- npm

### Installation & Run

```bash
# Clone the repository
git clone https://github.com/ALI108-dotcom/MyPortfolio.git

# Navigate into the project directory
cd MyPortfolio

# Install dependencies
npm install

# Start development server
npm run dev

# Or build and preview production server
npm run build
npm run preview
```

### Accessing Edit Mode
- Open the site in your browser.
- Press <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>E</kbd>.
- Enter the administrator password to unlock the CMS Dashboard.
